# Day 2/60 - Prompt Engineering 💡 #60DaysClaudeChallenge
   
   ## Kya Seekha?
   Prompt better → Output better. AI ko clear role, context, format dena zaroori hai.
   
   ## Mera Example: AWS EC2
   ❌ **Bad Prompt:** `EC2 kya hai`
   ✅ **Good Prompt:** `Act as AWS teacher. Explain EC2 to B.Tech student using Zomato delivery boy example in Hinglish. 3 points only.`
   
   **Result:** Good prompt se ekdum simple answer mila with Zomato example.
   
   ## Mere 3 Prompt Rules:
   1. **Role do** - "Act as my mentor"
   2. **Context do** - "Main B.Tech 4rth year hun" 
   3. **Format bolo** - "3 points me, example ke saath"
